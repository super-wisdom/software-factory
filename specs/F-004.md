# Spec: Project init command

ID: F-004   Derived from: intent/F-004.md   Status: accepted
Skills applied: artifact-chain

## Summary
Add `factory init <name>` that writes a fresh project's line from a scaffold bundled in the
package. Paths containing `__pkg__` are renamed to the project's package; content tokens
{{PROJECT_NAME}} / {{PACKAGE_NAME}} are substituted. Refuses a non-empty target.

## Requirements
- `factory init <name>` creates ./<name> (or uses cwd when name is ".").
- package_name(): derive a valid, importable package name from the project name
  (lowercase, non-alphanumerics -> "_"; prefix if it can't start an identifier).
- Write every bundled scaffold file, substituting the package dir name and the two tokens.
- The scaffold contains the reusable line only: CLAUDE.md, .claude/**, templates/**, the
  artifact dirs, Makefile, pyproject.toml, .gitignore, README, ci.yml, agent-evals.yml
  (which installs the factory CLI and runs `factory eval`), a fresh DELIVERY-TRACKER, and a
  minimal src/<pkg> + tests placeholder.
- Abort (non-zero, nothing written) if the target exists and is non-empty.
- Print a summary and the next steps.

## Non-functional
- Standard library only. Scaffold bundled as package data so a global install works offline.

## Areas of concern (flagged)
- Bundling must survive pipx installs -> scaffold stored as a generated Python module
  (scaffold.py), guaranteed to ship with the wheel.

## Acceptance criteria
1. `factory init my-new-app` creates the tree; the package dir is `my_new_app`; tokens are
   substituted (e.g. core.py returns "my-new-app: ok").
2. The generated project's own `make check` is green (verified by running its pytest).
3. Initialising into a non-empty directory aborts with a non-zero exit.
4. package_name() maps "My Cool API" -> "my_cool_api" and prefixes names starting with a digit.
5. `make check` (this repo) is green.
