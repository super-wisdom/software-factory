# Intent: Eval runner

ID: F-002   Author: founder   Status: accepted
Date: 2026-08-31

## Problem
The agent-evals workflow is a placeholder. There's nothing that catches a regression in
agent config -- if someone edits CLAUDE.md, a skill, a hook, or a template and breaks an
invariant the `factory` tool or the agent depends on, nothing notices until it bites.

## Proposed outcome
A `factory eval` command that runs a suite of deterministic config-invariant checks from
evals/tasks/ and reports a pass rate, exiting non-zero below a threshold. Wire it into the
agent-evals workflow so config changes and a nightly cron are gated by it.

## Affected users and systems
The CLI (adds an `eval` subcommand + evals module), the agent-evals workflow, and evals/.
No change to product behaviour or to `factory new`.

## Constraints
- Python standard library only.
- Deterministic and dependency-free -- no live-agent/API calls in this tier (cost-clean).
- Must keep `make check` green.

## Out of scope
- Live-agent behavioural evals (running Claude on tasks and grading output) -- a heavier
  later tier once this deterministic net is in place.

## Open questions
- Task format: JSON files (stdlib) with cmd + expected exit/substring. Resolved.
